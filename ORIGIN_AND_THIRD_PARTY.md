# Происхождение кода и сторонние компоненты

Здесь перечислено, откуда взялась каждая часть VELUM//TEGRA Next: что написано
для проекта, что подключено как библиотека и что приложение скачивает или ставит
на сервер пользователя во время работы.

## 1. Собственный код проекта

- **VELUM//TEGRA Next** — Android-приложение для управления VPS с панелью 3x-ui.
  Оно написано заново на месте старого приложения автора «XUI Mobile». Старое
  приложение использовалось только как образец поведения. Его код в проект
  не переносился.
- Весь код в `app/`, `feature/` и `core/` написан для этого проекта. Это Kotlin,
  Jetpack Compose и Room.
- Тесты, приёмочные скрипты `RUN_PHASE*.ps1` и инструменты в `tools/` тоже
  написаны для проекта.
- Серверные скрипты `app/src/main/assets/velum-ssh-port.sh` (смена SSH-порта
  с откатом) и `velum-as-blocklist.sh` (блок-лист AS) — собственные. Блок-лист
  скачивает данные из внешнего источника, см. раздел 3.
- В `docs/` лежат этапные документы разработки, протоколы проверок и хандоффы.
  IP-адреса в них и в тестах — адреса тестовых серверов автора или
  документационные диапазоны RFC 5737 (`192.0.2.x`, `198.51.100.x`, `203.0.113.x`).
- В разработке участвовали ИИ-ассистенты: OpenAI Codex/GPT и Anthropic Claude.
  Они работали под руководством и с проверкой автора.

Приватные ключи в тестах — фиктивные заглушки. Настоящих ключей, паролей,
токенов и файлов подписи в репозитории нет. Подпись релиза берётся только
из переменных окружения `VELUM_RELEASE_*`.

## 3. Что приложение скачивает или запускает во время работы

В репозитории этих компонентов нет. Приложение получает их из официальных
источников по действию пользователя или ставит на его собственный сервер.

| Компонент | Источник | Где используется | Лицензия |
|---|---|---|---|
| **3x-ui** — панель управления Xray | github.com/MHSanaei/3x-ui, официальные выпуски | Устанавливается и обновляется на VPS пользователя. Раздел «Веб-панель» показывает оригинальный веб-интерфейс 3x-ui во WebView, без переделки. | GPL-3.0 |
| **Xray-core** | github.com/XTLS/Xray-core (в составе 3x-ui) | На VPS пользователя | MPL-2.0 |
| **GeoLite2 Country** | MaxMind, зеркало github.com/P3TERX/GeoLite.mmdb | Скачивается в телефон для сканера. *This product includes GeoLite2 data created by MaxMind, available from https://www.maxmind.com.* | GeoLite2 EULA (MaxMind) |
| **Списки AS-сетей** | github.com/C24Be/AS_Network_List | Скачиваются на VPS скриптом блок-листа | см. репозиторий источника |
| **acme.sh** | вызывается через меню x-ui | Выпуск TLS-сертификатов на VPS | GPL-3.0 |
| nginx, sqlite3, curl, fail2ban, systemd | пакеты дистрибутива (apt) | На VPS пользователя | лицензии пакетов |

## 4. Лицензия проекта

Собственный код проекта (раздел 1) распространяется по лицензии **MIT** (файл `LICENSE`).
Его можно свободно использовать, изменять и распространять, в том числе в коммерческих
целях, если сохранено уведомление об авторских правах. Лицензия MIT не распространяется
на компоненты из разделов 2 и 3: у каждого из них своя лицензия, указанная выше.
Приложение не содержит кода 3x-ui или Xray-core. Эти программы ставятся на сервер
пользователя отдельно, по их собственным лицензиям GPL-3.0 и MPL-2.0.
