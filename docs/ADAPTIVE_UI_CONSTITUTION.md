# Adaptive presentation contract

This contract implements Architecture Constitution law 22. It adds no remote authority.

1. Presentation follows the available window width, including landscape, split-screen and foldables.
2. Home changes its action layout at 680 dp. Management facts stack below 720 dp. Content width is bounded on larger windows.
3. Every page remains scrollable with the keyboard and increased font scale. Interactive actions have standard Material touch targets.
4. Server, SSH access, installation and WebPanel identities remain separate. A page can display only the exact selected tuple.
5. Opening or resizing a page reads local metadata and the operation journal. It cannot start SSH, submit a login or mutate a VPS.
6. Screens render real evidence, including unverified, unavailable and uncertain states. A progress animation is not a success receipt.
7. Detailed server facts carry the actual observation time. A saved installation or completed check is not a continuously live server indicator.
8. The journal owns operation truth. ViewModels and saved UI state hold only exact operation pointers; restoration reads status without redispatch.
9. Consent is scoped to the selected installation and SSH metadata. Backgrounding, changed metadata or a changed target revokes pending review.
10. The original 3x-ui website remains the WebPanel interface. Native administration uses the established SSH/domain/runtime ports.
11. The accepted private WebPanel transport, certificate trust and resource ownership remain a separate regression boundary.

Acceptance: narrow/wide windows, increased font scale, scrolling, keyboard, Back, foreground restoration and exact-target error handling. A build is not visual acceptance.
