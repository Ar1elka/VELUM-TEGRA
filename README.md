# VELUM//TEGRA Next

Нативное Android-приложение для управления серверами с [3x-ui](https://github.com/MHSanaei/3x-ui) по SSH.
Это чистая переработка XUI Mobile: старое приложение служило только образцом поведения,
весь рабочий код написан заново.

## Возможности

- **Серверы и SSH.** Подключение по паролю или ключу, только с закреплённым ключом хоста
  (без «доверять всем» и без молчаливой подмены доступа). Пользовательские ключи
  Ed25519 поддерживаются на устройствах с доступной криптобиблиотекой. Секреты
  шифруются ключами из Android Keystore.
- **Обнаружение и диагностика.** Поиск существующей установки 3x-ui, проверка службы,
  версии, настроек и журналов только на чтение.
- **Установка и обслуживание.** Установка 3x-ui, перезапуск, восстановление, удаление и
  переустановка с предварительной проверкой, подтверждением и проверкой результата.
  Команды не повторяются вслепую после обрыва связи.
- **Веб-панель.** Открытие панели напрямую по HTTPS или через SSH-туннель, просмотр
  подключений, клиентов, трафика и состояния сервера.
- **Резервные копии.** Создание и проверка копии базы панели, сравнение и восстановление.
- **Сканер.** Подбор IP-адресов и SNI с проверкой TLS и ранжированием по задержке.
- **Публикация сайта.** Загрузка статического сайта на сервер с проверкой nginx, DNS и HTTPS.

Устойчивость к обрывам сети, остановке процесса и перезагрузке телефона заложена в общий
журнал операций: незавершённые изменения на сервере не повторяются, а сначала сверяются.

## Структура

| Модуль | Назначение |
|---|---|
| `app` | Android-приложение и интерфейс (Jetpack Compose) |
| `core:model`, `core:domain` | модели и правила предметной области |
| `core:data` | база Room, репозитории, журнал операций |
| `core:secrets` | хранение секретов в Android Keystore |
| `core:ssh` | SSH-транспорт на [mwiede/JSch](https://github.com/mwiede/jsch) |
| `core:runtime`, `core:runtime-android` | выполнение операций, восстановление после сбоев |
| `core:webpanel` | работа с веб-панелью 3x-ui |
| `core:scanner`, `core:scanner-android` | сканер IP и SNI |
| `core:site` | публикация сайта |
| `feature:home` | главный экран |

Архитектурные решения описаны в `docs/ARCHITECTURE_CONSTITUTION.md`, план интерфейса в
`docs/PRODUCT_UI_CANONICAL_ROADMAP.md`.

## Сборка

Нужны JDK 17 и Android SDK (platform `android-37.0`, build-tools `37.0.0`).

```bash
./gradlew :app:assembleDebug
```

Тесты JVM (так же, как в CI):

```bash
./gradlew :app:testDebugUnitTest :core:ssh:test :core:runtime:test :core:domain:test
```

Полный список задач CI находится в `.github/workflows/android-ci.yml`.
Подпись релиза берётся только из переменных окружения `VELUM_RELEASE_*`; ключей в репозитории нет.

## Состояние

Версия `2.0.0` для Android 7.0 и новее. Подписанный APK, контрольная сумма
и список изменений доступны в [GitHub Releases](https://github.com/Ar1elka/VELUM-TEGRA/releases).
Этот APK обновляет предыдущую сборку из GitHub. Отладочная сборка с суффиксом
`.next` устанавливается отдельно.

Подключения панели (inbounds) можно просматривать в приложении и редактировать
через веб-панель 3x-ui. Для обновления 3x-ui приложение проверяет текущую
установку и готовит пакет и резервную копию. История работ и проверок описана
в [HANDOFF_2026-11-15.md](HANDOFF_2026-11-15.md).
